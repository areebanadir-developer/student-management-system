# 🎓 Student Management System

A full-stack MERN Stack Student Management System built using React, Node.js, Express.js, and MongoDB.

## ✨ Features

- Add Student
- View Students
- Update Student
- Delete Student
- Search Student by Name
- Responsive Tailwind CSS UI
- SweetAlert2 Notifications

## 🛠️ Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Tailwind CSS
- Axios
- SweetAlert2

## 🚀 Installation

### Frontend

```bash
npm install
npm run dev
```

### Backend

```bash
cd student-management-backend
npm install
node server.js
```
